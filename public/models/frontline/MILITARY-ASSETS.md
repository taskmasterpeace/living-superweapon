# Original military equipment

The armored scout and clone helmet/carrier are original assets authored for this project. Their source Blender files, exact geometry contracts, previews, budgets and validation reports live under `assets-src/frontline-vehicles`, `assets-src/frontline-scout-articulation` and `assets-src/frontline-clone-kit`.

No Arma/CWR model, texture, sound or C++ implementation is included in these assets. CWR's open-source code release and its separately restricted game-asset license are not interchangeable.

The clone's existing underlying `superhero-male` body is from the Quaternius CC0 character bank; it is not included in `clone-kit.glb`. The current rifle and boot/forearm accessories are existing project geometry. The equipped clone is a distinct encounter definition, not a replacement of canonical SARGE or the player roster.

For separately licensed aircraft, see [aircraft credits](AIRCRAFT-LICENSE.md). Aircraft remain presentation actors, not playable/armed aircraft. Ground scouts have a limited remote rifle station in the optional Front Line encounter; driving is not implemented.
