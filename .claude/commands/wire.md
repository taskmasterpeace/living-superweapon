---
description: Wire an existing-but-isolated system into actual gameplay
---
Use the `wwa-wire-in` skill on: $ARGUMENTS

Answer its five questions explicitly before writing any code:
- which existing CHOKE POINT does this route through
- which player-facing DOOR does it need (a mode card, a screen, a key, a slot)
- which other systems should READ it, so it is not a leaf
- what does the player FEEL differently, in their own words
- what new DECISION does it create

If the effect is currently described in PROSE in a data file rather than as a field, say so — that
is unreachable content by construction and the fix is a field, not a renderer.
