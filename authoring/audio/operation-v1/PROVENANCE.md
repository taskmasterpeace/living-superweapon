# operation-v1 audio — provenance ledger

**Every operation-v1 asset is ORIGINAL DETERMINISTIC DSP SYNTHESIS** — WAV masters in
`authoring/audio/operation-v1/masters/`, MP3 derivatives in `public/audio/operation-v1/`. There is
no third-party sample, no AI audio model, and no recorded or cloned human voice anywhere in this set.
Each asset is generated in-repo from `authoring/audio/operation-v1/recipes.mjs` (built on the
dependency-free `synth.mjs`), so given the same seed the WAV bytes are reproducible byte-for-byte.

This satisfies the project audio contract (`docs/AUDIO_SOURCES.md`, `src/core/audio.js` header):

> Every sound is either a CC0 recording we hold on disk, **or DSP we wrote driven by
> engine-computed parameters.** Nothing is ever produced by an AI audio model.

These are the second kind, pre-rendered to files.

## Source / method / license

| Field | Value |
|---|---|
| Source | Original synthesis — `authoring/audio/operation-v1/{synth.mjs,recipes.mjs}` on branch `codex/pw-operation-audio` |
| Model / generator | **None.** Hand-written DSP (oscillators, RBJ biquads, envelopes, ring-mod, softclip, seeded noise). No AI audio model. |
| Voice | **No recorded or cloned human voice.** The zombie set is synthesised creature vocalisation (glottal saw + formant band-passes + noise); squad/pursuit "voice" cues are non-verbal radio tones. |
| Prompt | N/A (not a prompted generator) |
| Determinism | Seed = `fnv1a(cueId + '#' + variant)`; `mulberry32` PRNG; no `Math.random`. Re-running the build reproduces identical WAV masters (checked by `tools/operation-audio.test.mjs`). |
| Masters | 16-bit PCM WAV, 44100 Hz, mono (the authoritative reproducible artifact) |
| Derivatives | MP3 via ffmpeg `-ac 1 -ar 44100 -b:a 96k -map_metadata -1 -codec:a libmp3lame` — matches the existing library format |
| Encoder | ffmpeg 8.1.2-full_build-www.gyan.dev (recorded in `manifest.json`) |
| License | **Original project-owned work.** No third-party source → no external license obligation. May be released CC0 at the project's discretion; not labelled CC0 here without a formal decision (per the handoff's "do not label generated assets CC0 without evidence" rule). |
| Peak / duration | Measured per file below and in `manifest.json`; peak-normalised, no clipping (all < 0 dBFS). |
