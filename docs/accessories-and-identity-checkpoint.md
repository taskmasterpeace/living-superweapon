# Accessories and identity checkpoint

Creator categories now group body, hair/face, clothes/colors, accessories, tattoos/emblems, auras, animation and saving. Per-character editable tasks persist under power-world.creator-review.v1 and export as JSON. Approval timestamps reopen when recipe values change. Tasks track artwork/placement review; the user is not expected to repair code defects.

Gold chain is a reusable checkbox, demonstrated on Moses. Simple emblems should read at small scale: strong silhouette, transparent background, few colors. Moses has a replaceable Uganda-flag-colored crowned crane; source: https://abuja.mofa.go.ug/uganda/crested-crane . This is an original stylized graphic, not an official insignia reproduction.
