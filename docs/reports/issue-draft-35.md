## Outcome
One standalone Animation Library linked from the character creator/hub, using the shared Impact styling. Include current content, not an empty future asset browser. Combat and movement are the first consumers.
## Inventory and organization
Discover existing strike-bank, heavy-strike-bank, locomotion-bank, jump-bank, martial definitions and procedural flight, guard, grab, carry, throw, KO and recovery poses. Stable IDs; categories; source and rig compatibility; character assignments; grounded/airborne and weapon tags. Distinguish authored clips from procedural recipes and planned/missing content.
## Quality of life
Search/filter/sort, favorites, recent entries, character preview, play/pause, scrub, slow motion, frame step, reset view, timing markers, duplicate variant, revert edits, explicit save/export and missing/incompatible warnings. Show which characters use an entry before edits. Safe mirrored previews only where the rig supports them.
## Native pipeline
Reuse existing import/retargeting and runtime systems. Keep damage/reach/energy in attack profiles; clips reference profiles and contact markers rather than becoming another balance authority. Shared move families with per-character approach/reach/speed settings; no bespoke animation set required for every hero. Versioned manifest and validation; newly added entries appear automatically. Give future content workers a scoped handoff and example export.
## Acceptance
Existing animation counts reconcile to source. Edit one shared punch and verify intended users, blocked/missed/contact outcomes and revert. Assign a compatible variant to one hero without changing others. Preview current flight/carry/fall content. Native melee and traversal remain authoritative. Capture short native clips and label posed previews separately.
