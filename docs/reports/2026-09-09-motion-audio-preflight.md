### Source cadence is not the existing footstep clock

`src/engine/ground-motion.js:51` blends walk/jog/sprint by speed/body scale. Line 53 advances the **existing normalized source phase** by signed travel speed / blended stride, frozen by hitstop; lines 54–57 sample all three takes at that phase. In contrast, footsteps use the unrelated `animT*12` crossings, approximately 3.82 opportunities per simulation second regardless of stride speed. `animT` itself advances before the hitstop early return (`src/engine/entity.js:1166`, `:1535`). Merely copying today's step block into Studio would reproduce the wrong cadence, and would leave standard Studio Walk silent.

The checked `src/data/locomotion-bank.json:1` identifies Quaternius Universal Animation Library Standard, `AnimationLibrary_Godot_Standard.gltf`, sampled at 60Hz: `Walk_Loop` 1.333333s/81 frames, `Jog_Fwd_Loop` .916667s/56 frames, `Sprint_Loop` .666667s/41 frames. These durations are provenance, **not a replacement playback timer**: runtime speed scales the phase. The bank has no foot-contact event markers. `tools/lib/quaternius-source.mjs:96` samples actual takes; `:113`–`:129` retain the raw endpoint and apply a four-frame seam correction. Any contact metadata must be measured against source and final target support, including that wrap, rather than assuming contacts at phases 0 and .5.

Jump's .30s takeoff / .36s landing presentation windows (`src/engine/jump-motion.js:9`) must not schedule sounds. Its state follows real air/support at lines 33–39; physics remains the departure/contact authority.

## Proposal: bounded next slice, not implemented

1. **Share step events at the actual source/contact seam.** A small engine motion-audio helper should consume the current ground channel phase/weight/rig identity and final foot support once per positive simulation sample. First measure/validate per-foot contact transitions through source and final target playback; either consume those real support transitions or bake minimal source-derived contact metadata into the existing ingest. Handle phase wrap, retreat, stride blends and handoffs without replaying both blended takes' events. Preserve an explicitly separate procedural fallback when no source channel owns the legs. Do not add a `time += dt` audio oscillator, assume a step from a take-label change, or drive root/joints from audio.
2. **Use one caller per execution path and one native event authority.** Replace/move the old step dispatch rather than leaving both active. Native normal updates reach the helper after `_animate` has produced the final pose (`src/engine/entity.js:1539`–`:1545`); Studio pose-only motion reaches the same helper after line 280 using its existing delta. Physics takeoff/landing sites may forward their existing committed facts through the same adapter, preserving material/impact rules and positive-time gating. Do not infer impact strength after physics zeroes velocity. Ground jump (`src/tool/studio-preview.js:256`) and Studio melee (`src/tool/studio-melee.js:56`) already call full Fighter updates: **no additional Studio motion emitter on those branches**. Do not turn every Studio state into full gameplay updates just to obtain sound.
3. **Optional flight layer, bounded and explicitly authored.** Only if included in the next approved slice, select an existing local loop/DSP family and consume native flight ownership, speed, throttle/braking and alive state. Keep at most one motion-owned loop per Fighter (one subject in motion Studio), with hysteresis and gain/rate clamps; stopping/braking can modulate/fade that loop instead of repeatedly firing a brake cue. Do not make every hero a rocket, add a hover bed by default, or double native afterburner audio. Studio's synthetic `_burnT` must not trigger native ignition/drain sounds. A real ignition rehearsal requires the native transition/upkeep path, not an event at a scripted “boost” timestamp. No new asset is needed for the shared step/transport slice.

The helper needs only bounded per-Fighter observation state (rig/source identity, last consumed phase/contact/ownership, optional loop handle), not a global event scheduler. Evaluate muted reconstruction so the baseline follows reconstructed motion, but never queue missed sounds for later playback. Capture any diagnostics by value; do not retain mutable temporary vectors or an unbounded per-frame history.

### Time, interruption and disposal contract for that slice

| Boundary | Required behavior / existing seam |
|---|---|
| Positive live playback | Consume the one existing simulation sample and emit each contact once. Keep events position-aware through the existing AudioBus. |
| Pause / mute | Studio's setters already stop voices (`src/tool/studio-audio.js:35`–`:37`). Its stop disconnects old one-shot buses and retires active backend loops (`:61`–`:72`). Resume emits no historical one-shots; a still-live loop may restart on its next live `set`, not immediately from seek. |
| Scrub / reset / repeated same seek | Reconstruct silently; explicitly re-prime observer state and release the old motion facade on every seek/source reset, including pure-flight seeks that reuse the Fighter. Sound gating alone does not remove obsolete facade ownership. |
| Settle / zero delta | Pass zero **simulation** delta during all 90 settle samples even when the pose delta is positive. A zero-delta redraw neither emits nor advances event history. Initial/rebound baselines use an explicit reset, not a fake contact. Keep Ground jump's `dt>0 && !settling` guard. |
| Hitstop / frozen / KO | The motion emitter needs an explicit eligibility/ownership policy, not only `speed>8`. Hitstop skips physics but animates at line 1535; frozen physics can still move a fighter (`src/engine/entity.js:1428`). A sliding ice shell or thrown body is not walking. Suppress new footfalls when the leg channel is frozen or another owner has support; retire optional motion voices on KO. |
| Slow motion | Event cadence follows the already scaled simulation/pose phase. Audio fades and watchdog heartbeats retain their native clocks. If transport speed is later added, scale the existing delta once; do not add an audio timeline. Test substeps/catch-up so stale events cannot burst on resume. |
| Source/form/rig replacement, respawn, actor removal, close | Release the old loop facade, discard old rig/contact references and prime a fresh baseline. Call the same idempotent retirement from both KO and Fighter disposal, plus Studio seek/reset/dispose. `StudioAudio.dispose` stops everything, clears handles and closes its context (`src/tool/studio-audio.js:74`). |

Existing lifecycle limits must not be mistaken for a ready-made universal motion-loop contract: afterburner progression/voice updates run **before** the hitstop branch (`src/engine/entity.js:1215`, `:1535`). KO explicitly stops `_burnLoop` (`:1125`), whereas `dispose()` (`:644`–`:680`) has no explicit `_burnLoop.stop`; the gameplay watchdog provides eventual orphan retirement. Do not copy these omissions into a new motion loop or silently refactor ability lifetime in this slice. Retire owned handles explicitly; the 450ms watchdog is a fallback. A backend handle already reaped by that watchdog cannot be assumed resumable without recreation.
